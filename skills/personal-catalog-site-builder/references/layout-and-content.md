# Layout and content

| Page | Essential content | Behavior |
| --- | --- | --- |
| Home | Introduction, contact strip, catalog, field evidence, contact | Person first; clear next action |
| Category/brand | Consistent identity controls, category anchors, products | Shared order/filter logic |
| Product | Name, photos, model table, inquiry | Stable ID, direct link/reload, in-page previews |
| Catalog/inquiry | Search, selections, message | Preserve drafts; visible pending/error states |
| Private workspace | Overview, customers, inquiries, tasks, maintenance | Server-authenticated; private storage |

Use a dark introduction, white product sections, restrained typography and one spacing scale. Prefer system fonts to unnecessary remote font requests. Introduce real approved experience/employment; no invented claims. Contact strips combine recognizable icons with text and confirmed destinations. QR contacts need a dialog and copyable identifier, not invented add-friend URLs.

Brand controls share canvas, optical size and padding. Preserve mark proportions/colors unless authorized otherwise; remove image whitespace, never crop lettering or stretch marks. Don't invent brands to fill slots. Product cards show the whole product with `object-fit: contain`; intentional cover crops need an appropriate subject and user direction. Keep details, enlargement and inquiry as distinct actions.

Show production photographs generously and describe visible scenes without claiming ownership, capacity or certification. Photo groups precede grouped videos; group events by location. Video-only events need no fabricated photographs. Feature key process videos with larger cards while preserving playback aspect ratio.

Provide readable mobile type, visible focus, reduced-motion support, labeled buttons and comfortable touch targets. Long tables scroll within their own region rather than widening the page.

## Catalog integrity

One canonical product ID and explicit sort key drive home, category and selection pages. Parse decimal numeric prefixes as numbers; unnumbered items last, locale-aware names as tie-breaker. Retain IDs when names change. Case/whitespace normalization is safe; other matches require a verified alias table. Do not infer equivalent models from similar names/photos.

Deduplicate display rows by confirmed public fields (size, product code, supplied indices), retaining independent commercial source rows privately. Missing indices remain blank or a translated dash. Planned sizes have a separate status, never an availability claim. Search/pagination stay within the product and never expose private source metadata.

## Languages and brief

English/Spanish are starter examples, not mandatory languages. Translate navigation, alt text, model empty states, validation, dialogs, acknowledgments and metadata. Set document `lang` and retain locale in links. Names/codes stay separate from translated labels.

Brief fields: audience/action; approved introduction; categories/IDs; model sources/aliases; media inventory/order; languages; approved social/QR contacts; private workspace scope; host/auth/database; launch constraints. Continue reversible work while optional content is pending, mark placeholders and replace before launch.
